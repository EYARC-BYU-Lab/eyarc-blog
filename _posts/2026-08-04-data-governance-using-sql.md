This case introduces students data governance concepts through hands-on interaction with relational data using SQL. Students explore data quality, consistency, and control by querying and evaluating transactional data to identify issues such as missing values, duplicate records, and inconsistent classifications. The case emphasizes how governance policies are operationalized within data systems and how structured query tools can be used to monitor and enforce those policies. It also highlights the importance of strong data governance at the design stage to prevent downstream inefficiencies and reduce the need for extensive data cleaning.
